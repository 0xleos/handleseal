How a seal works一枚印怎么来

01

Hold an Agent ID先持有 Agent ID

The registry stores the bare handle, for example 218. This site displays it as 218.ai. The suffix is not part of the on-chain hash.注册表里的名字不带后缀，例如 218。本站显示为 218.ai。后缀不参与链上哈希。

02

Hash locally在本地做哈希

Paste text or pick a file. The browser computes keccak256. The file is never uploaded, and the text is not stored by this site.粘贴文字或选择文件。浏览器计算 keccak256。文件不会上传，文字也不会被本站保存。

03

Seal, or witness盖印，或见证

Sealing and witnessing use the same identity check. You cannot witness your own seal, and the same address can witness a seal only once.盖印和见证使用同一套身份校验。不能见证自己的印，同一个地址对同一枚印只能见证一次。

How to get an Agent ID如何获得 Agent ID

An Agent ID is a soulbound handle on chain 56. Register it in the wallet that holds your own agent account. Handleseal cannot register one for you.Agent ID 是链 56 上的灵魂绑定名字。请在持有你自己代理账户的钱包里注册。Handleseal 不能代你注册。

This site will not look up someone else's wallet from a handle. Verification is by seal id or content hash only.本站不会凭名字查询别人的钱包。核验只接受印记编号或内容哈希。

Written on the seal印上有什么

  • Your address, bare handle, and token id你的地址、不带后缀的名字、token id
  • The 32-byte content hash32 字节内容哈希
  • An optional public label, at most 80 bytes可选的公开标签，最多 80 字节
  • The time, and later witnesses时间，以及之后的见证

Stays on your device留在你的设备上

  • The file文件

  • Private keys and seed phrases — never asked for私钥和助记词——本站不会索取
  • Any account on this site — there is none本站账户——不存在
