Identity gate身份校验

  1. balanceOf(account) > 0
  2. handle = handleOf(account) ≠ ""
  3. tokenId = uint256(keccak256(bytes(handle)))
  4. ownerOf(tokenId) == account

handleOf returns the bare handle, such as 218, not 218.ai. ownerOfHandle is not called. ownerOfHandle("218.ai") is not a gate.handleOf 返回不带后缀的名字，例如 218，而不是 218.ai。合约不调用 ownerOfHandle。ownerOfHandle("218.ai") 不是校验条件。

Agent wallet: preview, then confirm, then execute代理钱包：先预览，确认后才执行

Writes go through the official baw contract-call flow. Preview, show the parsed terms and risks, wait for an explicit yes, then execute. requireConfirmation: false does not skip that yes. A request to skip confirmation is refused.写操作只走官方 baw contract-call 流程。先预览，展示解析后的条款和风险，等到明确的同意，再执行。requireConfirmation: false 也不能跳过这一次同意。要求跳过确认的请求会被拒绝。
